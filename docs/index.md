# 🚀 Lifecycle Mastery: Managing Power Platform and Agents

As AI agents take center stage in what you build and how you build it, the need for robust, scalable, and secure application lifecycle management (ALM) has never been more critical. This hands-on workshop will help you master the lifecycle of Power Platform solutions, agents, and how to deploy and operate them together - ensuring intelligence, governance and agility go hand in hand.

## 🎯 Topics covered

- ALM and DevOps fundamentals, environment strategy, and solution management
- Managed and unmanaged solutions, metadata and data, connection references, and environment variables
- Source control, team development, and code-first inner-loop workflows
- Deployment Pipelines, environment groups and routing, approvals, and governance
- Lifecycle management for Copilot Studio agents, Power Apps code apps, Power Pages, Managed Apps, and Managed Agents
- Security posture and deployment guidance for operating solutions and agents at scale

## 🚀 Getting Started

> **💡 Tip:** For a browser-friendly visualization, visit <https://microsoft.github.io/PPCC26-ALM>

Choose either format to follow the labs:

- **Interactive lab guide:** Open the [workshop app](https://microsoft.github.io/PPCC26-ALM/labs/Lab%20Guide/PPCC26%20ALM%20Workshop%20-%20Lab%20Guide.html#/home), choose a lab, and follow its steps.
- **Written lab guides:** Start with [Lab 1: Setup](labs/lab1/lab1.md), then follow the labs in sequence using the links in the agenda.

Both are options for following the workshop; you do not need to complete the labs twice. If the formats differ, follow the written lab guide's current instructions and environment names. In Lab 2, build in **Development 1** and deploy to **Development 2**, even if the app shows an older target name.
